# sarto

Take a newly released open-weights model and turn it into something usable on an Apple Silicon Mac with limited memory.

Status: planning. The roadmap lives in the issue labelled `wayfinder:map`. Vocabulary: [GLOSSARY.md](GLOSSARY.md).

## Contributing

Never commit credentials, tokens, or model weights. A `gitleaks` pre-commit hook guards this; install it with `pre-commit install`.
